# SLOTU — Product Requirements Document

## Original Problem Statement
Build a complete production-ready website and backend system for SLOTU — a trusted subscription slot-sharing marketplace for India. SLOTU solves scam-prone manual slot trading on Reddit/Telegram/DMs by acting as a structured marketplace with escrow payments, verified sellers, and instant automated credential delivery. SLOTU is an intermediary (like OLX/eBay), not the account holder. Protected under IT Act 2000 §79.

User scoped first iteration to: **landing page only, static, design-led**.

## Tech Stack (decided)
- Frontend: React (CRA) + Tailwind + Shadcn UI + Framer Motion + react-icons
- Backend: FastAPI + MongoDB (deferred — not needed for static landing page)
- Originally requested PostgreSQL/Redis/Celery/Cashfree — to be revisited when building app/backend
