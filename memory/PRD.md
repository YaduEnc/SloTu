# SLOTU — Product Requirements Document

## Original Problem Statement
Trusted subscription slot-sharing marketplace for India with escrow payments, verified sellers, and instant credential delivery. Intermediary under IT Act 2000 §79.

## Tech Stack (decided)
- Frontend: React (CRA) + Tailwind + Shadcn UI + Framer Motion + react-icons
- Backend: deferred — comprehensive build spec produced at `/app/documentation/`

## Design System
- Dark mode (Swiss & High-Contrast). zinc-950 base, emerald-500 accent.
- Headings: Outfit. Body: Manrope. Mono: JetBrains Mono.
- Generated by design_agent_full_stack — see `/app/design_guidelines.json`.

## What's Implemented (2026-12)

### Landing page (full marketing site, static)
- Sticky scroll-aware navbar (transparent at top → glass on scroll, scroll-spy active link, mobile hamburger menu)
- Hero with floating bento card composition
- Stats strip with animated count-up on view
- "How it works" 4-step grid
- Services marquee (2 rows, infinite scroll, pause on hover, brand colour reveal)
- Live activity ticker (pseudo feed for pre-launch social proof)
- Trust & escrow split section with live escrow flow visual + 4 features
- Comparison table — Slotu vs Telegram/DMs
- For Sellers earnings calculator (Shadcn Slider — slots, price, days)
- Pricing transparency (Standard 5–8% vs Pro ₹199/mo)
- FAQ accordion (8 common questions)
- Static waitlist (Shadcn Tabs buyer/seller, name, email, toast success)
- Watermarked footer with social + 5 footer columns

### Routed pages
- `/` Landing
- `/terms` Terms of Service
- `/privacy` Privacy Policy (DPDP Act 2023)
- `/refund` Refund Policy
- `/grievance` Grievance Officer (IT Rules 2021)
- `/cookies` Cookie Policy
- `/about` About Slotu
- `/contact` Contact (4 channels)
- `/*` 404 NotFound page (on-brand)

### Backend handoff documentation
- `/app/documentation/` — 19 files, ~3500 lines of spec
- Files: README, QUICK_PROMPT, 00–15 master docs, frontend-types.ts
- Covers: project context, master build prompt, tech stack, full PostgreSQL schema, every API endpoint, Fast2SMS OTP auth, escrow state machine, Cashfree Payments + Payouts, AES-256-GCM credential vault, Celery Beat jobs, notifications, admin panel, frontend API contract, security/legal, env vars, testing checklist
- `frontend-types.ts` is single source of truth for backend Pydantic shapes
