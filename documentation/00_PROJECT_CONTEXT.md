# 00 — SLOTU Project Context

## What is SLOTU

SLOTU is a **trusted subscription slot-sharing marketplace for India**. Indians today buy and sell slots on shared digital subscriptions (Netflix family plan, Spotify duo, Canva Pro team, etc.) through Reddit, Telegram and random DMs — which is scam-prone, unstructured, and unprotected.

SLOTU brings **trust, automation, and safety** to this market by acting as a structured marketplace with:
- **Escrow payments** — Slotu holds buyer's money until access is confirmed
- **Verified sellers** — phone OTP + UPI ID + Aadhaar verification
- **Instant credential delivery** — credentials/family-plan invites delivered automatically the moment payment confirms
- **Trust scores** — built from real verified transactions
- **24-hour auto-refund** — if access fails

SLOTU is **NOT the account holder**. SLOTU is the marketplace **intermediary** — like OLX or eBay but for subscription slots. Protected under **Section 79 of India's IT Act 2000** (safe harbour for intermediaries).

## How it works

### Buyer flow
1. Browse listings filtered by service / price / duration
2. Select a slot from a verified seller
3. Pay via UPI or card → money goes into **Slotu escrow** (NOT seller)
4. Seller is notified to deliver access
5. Buyer receives credentials or family-plan invite **automatically**
6. Buyer confirms access works within 24 hours
7. Slotu releases payout to seller, minus platform fee
8. If buyer disputes or doesn't act → **automatic full refund** logic

### Seller flow
1. Register with phone OTP
2. Complete seller verification (UPI ID + Aadhaar OTP)
3. Create listing (service, price, duration, slots available)
4. Upload credentials or family-plan invite method to **encrypted vault**
5. Get notified on each sale
6. Funds released to UPI / bank after buyer confirms
7. Build trust score over transaction history
